# RANK Leather

A premium leather brand website built with **Next.js 16**, **React 19**, and **Tailwind CSS**.

Designed with a modern luxury aesthetic, responsive layouts, animated interactions, product galleries, blog systems, and SEO-focused architecture.

---

# Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Lucide React
- Motion

---

# Features

- Fully responsive premium UI
- Animated fullscreen mobile navigation
- Dynamic product category pages
- Product gallery layouts
- Blog listing and blog detail pages
- SEO metadata generation
- Dynamic routing using App Router
- Optimized image handling with `next/image`
- Smooth transitions and hover animations
- Infinite marquee sliders
- Mobile-first responsive typography
